# ImageReducer logo

Created using the built-in image-generation tool. The PNG is in `ImageReducer-logo.png`; the Windows ICO is in `ImageReducer.ico`. The PNG is included in the application header and window icon, and the ICO is embedded in the executable. Format conversion to ICO preserves the generated design.

Generation prompt:

> Use case: logo-brand. Create a polished app icon/logo mark for ImageReducer, a free Windows image compression utility. Single centered icon, no text or letters. A simple rounded blue square containing a white photo/mountain symbol with a small pair of inward-pointing arrows conveying reduction. Clean bold geometric design, blue and teal accents, minimal flat vector-like style, excellent readability as a 32px Windows icon. Transparent background outside the rounded square. Square canvas, mark occupies about 85 percent of canvas. No mockup, no shadows, no gradients, no extra variations. Save as a PNG logo asset.
