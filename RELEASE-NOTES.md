# ImageReducer 1.3.0

ImageReducer by **CTP · ctp@ctp.cc**

- Bulk JPG/JPEG, WebP, HEIC/HEIF, PNG and BMP input.
- Per-image limits of 1 MB, 2 MB, or a custom maximum.
- JPEG, WebP and PNG exports with automatic compression and resizing.
- Remembered save folder and editable filename prefixes and suffixes.
- Compact interface with fixed action buttons and a CTP credit.
- Click the credit to read the ImageReducer Attribution License.
- Includes required third-party notices and decoder source materials.

Extract the entire Windows ZIP and run ImageReducer.exe. The app is portable
and unsigned. Application source is not included in this distribution.
